# Williams Elusakin — Computing Project

This repository brings together four projects from my computer science work: a Flask task API, Pac-Man search agents, a Linux file manager, and a C++ data-structure visualizer.

## Projects

| Project | Languages and tools | What to explore |
|---|---|---|
| [Task Manager REST API](task-manager-api/README.md) | Python, Flask, SQLAlchemy, SQLite | Full source and tests are included here; the standalone public repo is [welusakin/task-manager](https://github.com/welusakin/task-manager). |
| [Pac-Man Search Agents](pacman-search-agents/README.md) | Python | DFS, BFS, uniform-cost search, A*, corner goals, food-collection goals, and heuristic comparisons. |
| [System-Level File Manager](system-file-manager/README.md) | C, POSIX/Linux system calls | A modular command loop for directory navigation and common file operations with explicit error handling. |
| [Data Structures Visualizer](data-structures-visualizer/README.md) | C++17, object-oriented design | Stack, queue, and binary search tree operations with step-by-step state output. |

## About these projects

The Task Manager API source and tests are included and linked to the standalone public repository. The other three programs are independent implementations based on the features and scope in my project notes; their original class submission files were not available. Each project is complete enough to build and run, and its README explains the functionality and setup. These are current implementations, not archived copies of the original coursework.

Each project has its own setup instructions and build or run commands. No external service, API key, or private data is required.
